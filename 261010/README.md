# Linux 및 Python 기초 과제

## 소개

이 폴더에는 Linux 기본 명령어와 Python 기초 문법을 실습한 자료가 포함되어 있습니다. Python에서는 자료형과 리스트, 반복문, 리스트 컴프리헨션, `enumerate`와 `zip`, 딕셔너리 및 JSON/YAML 파일 처리를 다룹니다. NumPy를 이용한 배열 생성·변환·정규화·통계 연산과 학생 성적 데이터 분석도 포함합니다.

## 폴더 구성

```text
실습 및 과제/
└── 10_10/
    ├── 01_Linux-and-Python.ipynb
    ├── 맹구_개인정보.json
    ├── 맹구_개인정보.yaml
    └── .vscode/
        └── settings.json
```

- `10_10/01_Linux-and-Python.ipynb`: 10월 10일 실습 노트북
- `10_10/맹구_개인정보.json`, `10_10/맹구_개인정보.yaml`: 딕셔너리 데이터를 JSON/YAML로 저장한 실습 결과
- `10_10/.vscode/settings.json`: VS Code 작업공간 설정

## 실행 방법

1. 저장소를 clone한 뒤 Jupyter Notebook을 지원하는 환경에서 노트북을 엽니다.
2. 필요한 패키지(예: NumPy, PyYAML)가 설치되어 있는지 확인합니다.
3. 노트북 셀을 위에서부터 순서대로 실행합니다.
